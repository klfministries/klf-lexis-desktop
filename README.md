# KLF Lexis for Windows

The desktop app for **[KLF Lexis](https://klflexis.com)** — the Bible study,
biblical language and ministry platform by KLF Ministries.

## Download

**[Download the latest version for Windows](https://github.com/klfministries/klf-lexis-desktop/releases/latest/download/KLF-Lexis-Setup.exe)**

Or from <https://klflexis.com/downloads/KLF-Lexis-Setup.exe>.

### Installing

1. Run `KLF-Lexis-Setup.exe`.
2. Windows may show a security prompt — click **More info** → **Run anyway**.
   The app is not code-signed yet, so SmartScreen warns about it on first run.
3. Choose where to install. Desktop and Start Menu shortcuts are created for you.

Requires **Windows 10 or 11 (64-bit)** and an internet connection. The app is
free — sign in with the KLF Lexis account you already have.

## What it is

A dedicated window for KLF Lexis: your library, notes and the original
languages, with no browser tabs around them. The window remembers its size and
position, links to other sites open in your normal browser, and you stay signed
in between sessions.
